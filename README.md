# creative-journalism-portfolio
A creative portfolio featuring Lorelei Skurzewski's visual journalistic work. This portfolio covers editorial design, graphic design and photography from Vox Magazine and the Columbia Missourian.
The website was created from HTML and CSS code by Lorelei Skurzewski with the assistance of AI to learn new features to include in the code that Skurzewski did not have prior knowledge on. The photos and artwork were all created by Skurzewski and each written statement is her own as well.
